## 2025-02-12 - [Dashboard and Analytics Month-by-Month Sequential Loop Anti-pattern]
**Learning:** In multi-tenant systems like Dental Lab Mate Pro, dashboard and analytics endpoints often calculate historic monthly breakdowns (such as 6-month revenues, case volumes, etc.). When written with sequential `for` loops containing `await prisma.xxx`, this leads to a severe N-roundtrips database latency bottleneck. Parallelizing these with `Promise.all` yields a direct 6x reduction in query-roundtrip overhead while preserving deterministic results.
**Action:** When inspecting or building dashboard/analytics routes, scan for chronological query loops and parallelize them via mapped promises and `Promise.all`, being careful to handle type casting on the results to satisfy ESLint.
