## 2026-09-25 - Pre-fetching Relations and Batching Async Jobs in Cron/Worker Functions
**Learning:** In cron jobs and batch worker functions like `processUpcomingReminders`, calling individual handler functions that perform `findUnique` database queries for each item creates an N+1 query bottleneck. Pre-fetching `patient` and `dentist` relations in initial `findMany` queries and allowing handler functions to accept pre-fetched objects eliminates extra DB round-trips entirely. Additionally, dispatching jobs with `Promise.allSettled` processes notifications concurrently while maintaining error logging for rejected promises.
**Action:** Always inspect batch processing functions for N+1 DB calls inside iteration loops, pre-fetch relations in `findMany` queries, and use `Promise.allSettled` with error inspection for concurrent job execution.
